# 一日重置教练
> 配套 Dan Koe 文章《Fix Your Entire Life In 1 Day》的 AI Skill

## 简介
这不是日程管理工具，是**身份重置引导练习**。
核心思想：改变行为很难，先改变身份叙事，行为会自动对齐。
- 上午：心理挖掘，找到隐性卡点、反愿景、新身份
- 日间：6次定时觉察，打断自动驾驶模式
- 傍晚：洞见整合，输出可落地的目标与行动

启动时可选择「分段做」或「连续做」。连续做按原顺序完成三组题，每次问一题。日间六题回顾今天或最近一天的经历，答完直接进入傍晚整合。

## 开始使用

将整个 dan-koe-life-reset 文件夹复制到 Codex 的技能目录（例如 ~/.codex/skills/）。在 Codex 中输入 $dan-koe-life-reset，再说「启动一日重置」。

## 触发口令
- `启动一日重置` → 开始整套流程
- `开始傍晚整合` → 白天觉察完成后进入收尾模块
- `继续一日重置` → 在原聊天继续；换聊天时，把暂停时生成的续跑卡和口令一起发来
- `查看日间觉察清单` → 调取全天觉察问题

回答太笼统时，教练会先追问一个具体例子。你可以随时说「跳过」或「暂停」。暂停时会生成可复制的续跑卡。
